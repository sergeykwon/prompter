# Easy Prompter

대본 보면서 바로 촬영하는 **텔레프롬프터**. 모바일 · 아이패드 · 웹 세 가지 화면.

## 디자인 — 토스 스타일

- **컬러** — 배경 `#F2F4F6`, 카드 흰색, 포인트 `#3182F6`(토스 블루), 삭제 `#F04452`
- **그레이 9단계** — 본문 `g900 #191F28`, 보조 `g600 #6B7684`, 비활성 `g400 #B0B8C1`
- **형태** — 테두리 대신 흰 카드로 구분, 라운드 16px, 그림자 없음
- **버튼** — 주 버튼 56px 파랑 라운드 14px, 보조 버튼은 회색 배경
- **인터랙션** — 누르면 `scale(0.97)`, 바텀시트는 아래에서 올라옴
- **타이포** — Pretendard, 헤드라인 26px Bold `tracking -0.035em`

### 재생 화면만 어둡습니다

프롬터 재생 화면은 검정 배경 + 흰 글씨를 유지했습니다.
촬영 중 얼굴 앞의 밝은 화면은 피사체에 반사되고, 어두운 환경에서 눈이 부십니다.
대신 강조색은 토스 블루로 통일하고 컨트롤 모양도 앱과 같은 규칙을 씁니다.

## 세 가지 화면

화면 폭과 포인터 정밀도로 자동 판별합니다 (`lib/device.ts`).
터치 기기는 화면이 넓어도 태블릿으로 봅니다 — 아이패드 Pro 가로가 여기 해당합니다.

| | 판별 조건 | 편집 화면 | 프롬터 | 기본 글자 |
|---|---|---|---|---|
| **모바일** | `< 768px` | 1단 · 화면 전환 이동 | 2행 컨트롤 바 | 44pt |
| **아이패드** | `≥ 768px` 또는 터치 기기 | 2단 (목록 \| 편집) | 1행 컨트롤 바 | 62pt |
| **웹** | `≥ 1280px` + 정밀 포인터 | 3단 (목록 \| 편집 \| 설정) | 1행 + 단축키 안내 | 64pt |

- 글자 크기는 **화면별로 따로 저장**됩니다. 폰에서 맞춘 44pt가 웹에서는 너무 작습니다.
- 본문 폭도 화면별로 다릅니다 (모바일 980 / 아이패드 1200 / 웹 1500px).
- 웹은 설정이 우측 레일에 상주하고, 모바일·아이패드는 바텀시트로 엽니다.

## 기능

- **자동 스크롤** — 대본이 시선 유도선 위로 흘러갑니다
- **속도는 "자/분"** — 실제 말하기 속도 기준이라 예상 시간이 그대로 촬영 길이가 됩니다
- **재생 중 실시간 조절** — 속도, 글자 크기를 멈추지 않고 변경 (진행 위치 유지)
- **시선 유도선** — 카메라 렌즈에 가까운 높이에 읽는 줄을 고정. 위치 조절 가능
- **미러 모드** — 빔스플리터 프롬터 리그용 좌우 반전
- **3초 카운트다운** — 탭하고 자세 잡을 시간
- **화면 꺼짐 방지** — Wake Lock API
- **대본 저장** — 브라우저에 여러 대본 보관 (서버 없음, 계정 없음)
- **키보드 조작** — 스페이스 재생 / ↑↓ 위치 / ←→ 속도 / Esc 나가기

## 스크롤 속도 계산

속도를 px/s로 두면 글자 크기·화면 폭이 바뀔 때마다 실제 낭독 속도가 달라집니다.
그래서 이 앱은 **글자 수 기준**으로 계산합니다.

```
travel     = 대본 전체 높이(px)
pxPerChar  = travel / 공백제외_글자수
pxPerSec   = pxPerChar × (자per분 / 60)
총 소요시간 = 글자수 / 자per분  (화면 크기와 무관)
```

덕분에 아이폰 세로든 웹 가로든 **같은 대본은 같은 시간**에 끝납니다.
글자 크기나 창 크기를 바꾸면 높이를 다시 재고 진행률을 비례 보존합니다.

## 기술

- Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4
- 서버·API·DB 없음. 대본과 설정은 `localStorage`에만 저장됩니다.
- 스크롤은 `requestAnimationFrame` + `translate3d`. 프레임마다 React 리렌더 없이
  ref로 DOM을 직접 갱신합니다.

## 구조

```
app/
  layout.tsx          메타데이터 · 폰트 · 뷰포트(viewportFit: cover)
  page.tsx            화면별 레이아웃 분기 + 상태 관리
  globals.css         토스 디자인 토큰 · 모션
components/
  ScriptList.tsx      대본 목록 (variant: page | sidebar)
  Editor.tsx          제목/본문 편집 · 예상 시간
  Prompter.tsx        전체화면 프롬터 (스크롤 엔진 · 화면별 컨트롤)
  SettingsPanel.tsx   설정 (바텀시트 · 웹 레일 공용)
  ui.tsx              Wordmark / AppBar / PrimaryButton / Stepper / Toggle / Sheet
lib/
  device.ts           useDevice() — 화면 판별
  types.ts            Script · Settings · 화면별 상수
  store.ts            localStorage 입출력 (마이그레이션 포함)
  text.ts             글자 수 · 소요 시간 · 문단 분리
```

## 로컬 실행

```bash
npm install
npm run dev
```

주소창 없이 전체화면으로 실행됩니다.
